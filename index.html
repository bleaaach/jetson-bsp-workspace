支持状态

芯片/模块 驱动 CONFIG 状态 说明
Intel AX210 / AX200 iwlwifi CONFIG_IWLWIFI 支持 Wi-Fi 主模块

完整命令参考

# 初始化 BSP 环境
./jetson-bsp-workflow.sh init

# 下载 BSP 源码
./jetson-bsp-workflow.sh download R36.4.4

# 查询模块 (源码位置、CONFIG、依赖)
./jetson-bsp-workflow.sh query <module>

# 编译模块 (自动检测并启用 CONFIG)
./jetson-bsp-workflow.sh build <module>

# 推送到 Jetson 并加载
JETSON_HOST=user@jetson.local ./jetson-bsp-workflow.sh push <module>

# 一键编译 + 推送
JETSON_HOST=user@jetson.local ./jetson-bsp-workflow.sh deploy <module>

# 查看帮助
./jetson-bsp-workflow.sh help

工作流说明

自动配置流程：

  1. 检测模块对应的 CONFIG 名称
  2. 如果是 menuconfig 类型 (rtw89, iwlwifi)，自动启用父级和子模块
  3. 复制基础 .config 到 Build 目录
  4. 使用 scripts/config 启用目标 CONFIG
  5. 执行 make olddefconfig 展开依赖
  6. 编译目标模块及其依赖
  7. 可选：scp 到 Jetson + modprobe 验证
